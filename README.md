This repository contains all relevant materials for the benchmark control application documented in the following book chapter:

Previtali, D., Pitturelli, L., Previdi, F., Ferramosca, A. (2025). *Temperature Control of a Shrink Tunnel with Multiple Heating Zones*. In: Maestre, J.M., Ocampo-Martinez, C. (eds) Control Systems Benchmarks. Advances in Industrial Control. Springer, Cham. https://doi.org/10.1007/978-3-031-76312-0_4

Check out the file `benchmark_documentation.pdf` for additional information.
